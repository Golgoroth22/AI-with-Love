## 🤖 Ollama Chat App

Android-приложение для общения с локальной языковой моделью gemma:2b, запущенной через Ollama.

**Основные возможности:**
- 💬 Чат с AI в режиме реального времени
- 🏠 Работает с локально установленным Ollama (или на VPS)
- 🚀 Модель gemma:2b
- 📱 Современный Material Design 3 интерфейс
- 🔄 Поддержка истории сообщений

**Технические детали:**
- 🌐 HTTP API взаимодействие с Ollama
- 🎨 Jetpack Compose UI
- 🏗️ MVVM архитектура
- 💉 Koin для dependency injection
- ⚡ Kotlin Coroutines + Flow

---

## 🎯 Как использовать

### Использование приложения

1. **Запустите приложение** на Android устройстве или эмуляторе
2. **Убедитесь** что Ollama доступен по сети (настройте IP в SecureData.kt)
3. **Введите сообщение** в поле ввода чата
4. **Нажмите кнопку отправки** (иконка самолётика)
5. **Получите ответ** от gemma:2b модели
6. **Используйте "Новый чат"** для очистки истории

## 💡 Примеры запросов

### Простой вопрос
```

AI: Искусственный интеллект (ИИ) - это область компьютерных наук...
```

