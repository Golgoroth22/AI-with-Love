## Ollama Chat App — Юки, гид по Японии

Android-приложение для общения с AI-гидом по Японии «Юки», работающим на модели llama3.2:3b через Ollama. Пользователь пишет по-русски — модель отвечает по-английски, перевод происходит автоматически на устройстве через Google ML Kit.

**Основные возможности:**
- Чат с AI-гидом Юки на русском языке
- Автоматический перевод Ru↔En через Google ML Kit (on-device, без интернета)
- Работает с локально установленным Ollama
- Оптимизированные параметры модели: temperature, num_predict, num_ctx, top_p, repeat_penalty
- Современный Material Design 3 интерфейс

**Технические детали:**
- HTTP API взаимодействие с Ollama
- Jetpack Compose UI
- MVVM архитектура
- Koin для dependency injection
- Kotlin Coroutines + Flow
- Google ML Kit Translate (on-device Ru↔En)

## Как использовать

### Использование приложения

1. **Запустите приложение** на Android устройстве или эмуляторе
2. **Убедитесь** что Ollama доступен по сети (настройте IP в SecureData.kt)
3. **Введите вопрос о Японии** по-русски
4. **Нажмите кнопку отправки**
5. При первом запуске ML Kit скачает модели перевода (~10 МБ), далее работает офлайн
6. **Получите ответ** на русском языке

## Примеры запросов

```
User: Что посмотреть в Киото?
Юки: Киото — сердце традиционной Японии! Начните с района Хигасияма...
```

```
User: Расскажи о токийском метро
Юки: Токийское метро — одно из самых пунктуальных в мире...
```

```
User: Какую еду попробовать в Осаке?
Юки: Осака — гастрономическая столица Японии! Обязательно попробуйте...
```
