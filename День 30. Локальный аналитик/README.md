## Ollama Chat App — Юки + Локальный аналитик + Эмулятор ошибок

Android-приложение с тремя вкладками: AI-гид по Японии «Юки», локальный аналитик данных и эмулятор серверных ошибок. Всё работает на модели llama3.2:3b через Ollama. Пользователь пишет по-русски — перевод происходит автоматически на устройстве через Google ML Kit.

**Три вкладки:**

### Юки — чат с AI-гидом
- Общение с AI-гидом по Японии на русском языке
- Автоматический перевод Ru↔En через Google ML Kit (on-device, без интернета)
- История диалога хранится в английском языке (то, что видит модель)

### Аналитик — локальный анализ данных
- Загрузка CSV/JSON/TXT файлов с устройства для анализа
- Кнопка «Демо-данные» загружает сгенерированные ошибки из эмулятора
- Задавайте аналитические вопросы по данным на русском языке
- Модель анализирует данные и отвечает по-русски

### Эмулятор ошибок
- Симуляция серверных событий нажатием кнопки (6 типов событий)
- Записывает события в `generated_errors.csv` во внутреннем хранилище
- Цветовая кодировка: ERROR (красный), WARN (жёлтый), INFO (зелёный)
- Счётчик записей и список последних 8 событий в реальном времени
- Кнопка «Очистить» сбрасывает лог

**Типы событий:**

| Событие | Уровень | Сервис | Код |
|---|---|---|---|
| DB ошибка | ERROR | auth-service | DB_CONN_001 |
| Таймаут оплаты | ERROR | payment-service | GW_TIMEOUT_005 |
| SMTP ошибка | ERROR | notification-service | SMTP_ERR_004 |
| Поиск недоступен | ERROR | search-service | ES_CONN_009 |
| Медленный ответ | WARN | api-gateway | PERF_WARN_002 |
| Успешный вход | INFO | user-service | AUTH_OK_003 |

**Технические детали:**
- HTTP API взаимодействие с Ollama
- Jetpack Compose UI + Material Design 3
- MVVM архитектура (Screen → ViewModel → Repository)
- Koin для dependency injection
- Kotlin Coroutines + StateFlow
- Google ML Kit Translate (on-device Ru↔En)
- Внутреннее хранилище Android (`context.filesDir`) для CSV-лога

## Как использовать

### Подготовка

1. **Запустите приложение** на Android устройстве или эмуляторе
2. **Убедитесь** что Ollama доступен по сети (настройте IP в SecureData.kt)
3. При первом запуске ML Kit скачает модели перевода (~10 МБ), далее работает офлайн

### Рабочий процесс: Эмулятор → Аналитик

1. Перейдите на вкладку **«Эмулятор»**
2. Нажмите несколько кнопок для генерации событий (счётчик обновится)
3. Перейдите на вкладку **«Аналитик»**
4. Нажмите **«Демо-данные»** — загрузится `generated_errors.csv`
5. Задайте аналитический вопрос, например: *«Сколько ошибок DB_CONN_001?»*
6. Получите точный ответ от модели на русском языке
